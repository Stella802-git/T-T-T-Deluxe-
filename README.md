🎮 Tic-Tac-Toe Deluxe

A modern, arcade-inspired take on the classic Tic-Tac-Toe game, built with HTML, CSS, and JavaScript.

✨ About the Project

Tic-Tac-Toe Deluxe is a browser-based game where two players compete to get three matching marks in a row.

The game combines the familiar rules of Tic-Tac-Toe with an interactive canvas board, automatic win detection, and a live scoreboard.

🚀 Features

- Interactive 3×3 canvas game board.
- Two-player gameplay (X and O).
- Automatic turn switching.
- Win detection across rows, columns, and diagonals.
- Draw detection.
- Highlighted winning combinations.
- Live scoreboard for wins and draws.
- New Game and Reset Scores controls.
- Dark, neon-inspired interface.

🛠️ Built With

Technology| Purpose
HTML5| Page structure
CSS3| Styling and layout
JavaScript| Game logic and interactions
HTML Canvas| Drawing the game board and player marks

▶️ How to Run

1. Open "index.html" in your browser.
2. Start playing!

🎯 What I Learned

While building this project, I explored:

- Working with the HTML Canvas API.
- Handling mouse click events.
- Using coordinates to identify board positions.
- Managing game states and player turns.
- Working with arrays and winning combinations.
- Updating HTML elements using JavaScript.
- Detecting wins and draws programmatically.

👥 Gameplay

Tic-Tac-Toe Deluxe is designed for two players sharing one device.

Take turns placing your marks, aim for three in a row, and see who wins!
